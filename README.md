# 同花顺选股程序框架

一个可扩展的选股程序骨架，核心思路是：

> **数据源层（取数） → 策略层（你的规则） → 流水线编排 → 输出结果**

## 目录结构



## 低单票技术判读（今后每个标的固定分析流程）

**回答的问题**：对一只你认为"逻辑好、空间大"的票，当前强弱、何时是买点、上方空间有多少。

按「交易系统：均线(55/233) + 结构 + 时空(MACD·0轴) + 跨级共振 + 空间目标」五层来判，一条命令用真实历史K线出全部结果：

```bash
$env:DATA_SOURCE="hithink"
python scripts/analyze_stock.py 600519     # 换成任意6位代码
python scripts/analyze_stock.py 002241     # 歌尔股份示例
```

这条命令一次给出三层快照（详见 scripts/analyze_stock.py）：

1. **日K 均线55/233 + MACD 时空状态**——现价在55线上/下、233线上/下的相对位置；DIF/DEA 相对0轴的强弱区（强区/弱区/极强孕育/高位转弱/临界）。
2. **周K(大级别) + 日K(交易级别) 跨级共振**——判断"周线弱/日线强"这类分裂状态；**未完全共振**时，大级别弱会使小级别强的有效性打折（只轻仓试、别重仓追）。共振成立（周/日同处0轴上方双强）才谈中线主升。
3. **上方空间目标图**——历史前高档 + 黄金分割位（按近6年最低→最高全集），指出"第一道压力闸"，提醒空间是"阶梯式解锁"而非一竿子捅到底。

**沿用判读口诀（务必遵守）：**
- **强弱先问"哪个级别"**：大级别(周)定调，小级别(日)做细节；周弱则日强打折。
- **买点由技术扣扳机，不由"逻辑好/空间大"决定**——没站稳第一道压力前，上方远端目标只是"看的"。
- **空间目标 CSV** 由 `scripts/space_map.py`(或本命令) 写盘到 `results/<code>_space_map.csv`，供突破后逐档对照。

> 数据源与此通道只支持 **日/周/月(1d/1w/1mo)** 三种周期，**无60/15分钟K**；需要"精确日内扣点"须另接分钟级数据源，本通道不提供、也不编造分钟信号。

## 主升浪判断法则（判断"离主升浪还有多远"）

**目标**：给一只票当前所处阶段定档 A/B/C，回答"能不能、何时才到主升浪"。**不猜哪天爆发**，把"位置定性"+"等启动周确认"结合。

**判据（抄入口诀）**

```
先算两件事：
  ① 周K与日K 各自的 强弱区（DIF/DEA 相对0轴：强区0轴上/弱区0轴下/极强孕育）
  ② 距55线 = (现价 - MA55) / MA55

A 档 · 主升中后段(追高风险) = 周已0轴上强 且 距55>+22%(大幅脱离55加速)
                              → 例：招金黄金、赤峰黄金
B 档 · 主升初段/启动口(可顺势)= 周0轴上强 且 日0轴上强 且 距55未大幅拉离
                              → 例：深信服、财通证券
C→B · 临门一脚待确认          = 周0轴上强(大级别转好) 但 日线回踩55未翻红(未跟上周)
                              → 例：中信证券(周强日弱,贴55待日翻)
C 档 · 蓄势/未启(离主升最远)   = 周仍在0轴下(弱区)，价未站稳55上方
                              → 例：同花顺/歌尔(歌尔周弱日强也是C,因周定调)

启动确认周 = 当周放量大阳 + 价脱离55>~10% + DIF 重新上穿/加速(0轴上方金叉)
             只有出现它，才从"候选/临门"升级为"主升已启动"——C/前夜的票要等它。
```

**实战提醒（务必遵守）**
- **"前夜"当根K线无法 100% 确认本周必爆**——单看它往往混沌(价贴55、红绿徘徊)。它真正的价值是把你放进候补里，等"启动确认周"那根放量大阳再右侧加；**可以在前夜条件成立时轻仓试错 + 止损设55线下方，但绝不满仓赌某日发动**。
- **若错过启动，别在A档(距55已+22%以上)追高**——那是主升中后段，追高风险大。
- **周定调**：只要周线仍0轴下方(弱区)，即使日线翻到0轴上强，也只算 C（主升未启），日强打折，不追。

可复用实现：`strategy/main_wave.py`（`classify_single(周zone, 日zone, 距55)` → 返回 档位/可否买/该做什么），参数见 `config.MAIN_WAVE_RULE`。

## 左侧·安全垫判档（"跌不跌得下去 / 抗不抗第二脚"）

**注意两把尺，别混**（这就是"不同案例不同分析"的含义）：
- **右侧 main_wave(A/B/C)** = 会否进主升浪，**买入择时**用。
- **左侧 safe_ground(S/A/B/C)** = 这笔下方有没有底、贴不贴55、抗不抗大盘回踩，**持仓/抗跌评估**用。
- 同一只票两把尺可完全相反：已涨到高位=右侧"主升中枢A"，但左侧"已无垫、二脚回踩快"；跌成低位贴55=左侧"反抽/或见底"，能否当垫看企稳。

**判定要素**：日/周 MACD 强弱0轴 + 距55线 + 历史低位百分位 perc。

```bash
python -m strategy.safe_ground 300033 002241     # 默认两只，可任意加代码
```
说明：
- 以 ETF 为例当前同花顺数据通道**未开通场内ETF(159/516/560等)**，取不到其K线；
  可用该 ETF 的 **A 股成分代理**整体判板块强弱（如证券=中信/东财）。属近似、仅反映板块β，
  不等于能精确判某只 ETF 自身均线 — 不要当成独立担保。
- 数据仍然来自真实历史，结论只描述相对抗踩次序，**不承诺任何"必不跌"**。

档位表（safe_ground.py 顶部 docstring 有详表）：
- **S 厚垫**：历史低区 + 站回55上方 → 最抗跌
- **A 有垫**：站回55上方 + 位置中段 → 能扛不抗深跌
- **B 浅垫/半垫/贴55回踩/或见底**：破55即松动点
- **C 无垫**：仍在下降通道（周0轴下仍在55下）→ 最易被二脚踩，企稳前不加

## 低位判断策略（历史百分位法）

**回答的问题**：当前价格在过去的时间段里处于什么水平？

```
历史百分位 = (当前价 - 区间最低) / (区间最高 - 区间最低)
```
- 拉取股票过去若干年的**周K线**收盘价，找出最高/最低价；
- 计算当前价所处历史区间的百分位，**越接近 0 越低位**；
- 多周期综合：同时看长期(10年)/中期(3年)/短期(1年)，加权打分，避免单一周期误判。

### 参数说明（config.py 的 LOW_POSITION_RULE）

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `periods` | 多周期(年) + 权重 + 标签 | 10年/3年/1年，权重 0.5/0.3/0.2 |
| `method` | 低位判定方式 | `percentile` |
| `percentile_threshold` | 百分位 < 此值视为低位（底部20%） | `0.20` |
| `ma_threshold` | 均线偏离 < 此值视为低位 | `-0.30` |
| `resample_rule` | 周K重采样规则 | `W` |

### method 可选值
- `percentile` ：纯历史百分位法（默认，最直观）
- `ma_deviation` ：均线偏离法（低于长期周均线 30% 以上）
- `any` ：任一方式命中即低位
- `both` ：两种方式都命中才算低位

### 运行
```bash
# 对持仓/自选/观察集合分别跑低位判断
python scripts/analyze_low_position.py all
python scripts/analyze_low_position.py holdings
```


## 量价背离策略（低位放量）

识别长周期周K线上低平台+放量的量价背离现象，视为低位筹码快速集中信号。

```
背离分数 = 价格跌幅 x 成交量增幅 x 100
成交量增幅 > 50% 时额外 x1.5
```

- 平台期：连续 10 周内价格波动 < 15% 视为一个平台期；
- 背离：新平台期均价 < 前一平台期，但平均成交量更高 -> 一次背离；
- 对最近 5 个平台期按越近权重越高加权平均，映射到 0-100；
- 得分 > 30 视为强背离信号。

### 参数说明（config.py 的 VOLUME_DIVERGENCE_RULE）

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| lookback_years | 回看年数 | 3 |
| platform_window | 平台期识别窗口（周） | 10 |
| price_change_threshold | 平台期内价格波动上限 | 0.15 |
| min_platform_periods | 最小平台期持续周数 | 8 |
| top_n_platforms | 参与对比的最近平台期数量 | 5 |
| strong_signal_threshold | 强背离信号阈值 | 30 |
| volume_increase_bonus | 放量额外加分的阈值 | 0.5 |

纯计算函数 compute_divergence_score(周KDataFrame, params) 输入含 date/close/volume 的周K数据，返回 {score, is_strong_divergence, details}。

## 添加自己的选股规则

1. 在 `strategy/` 新建策略类，继承 `BaseStrategy` 并实现 `filter(stocks)`；
2. 把参数配置加入 `config.py`；
3. 在 `strategy/__init__.py` 导出；
4. 在 `pipeline.py` 的 `stages` 列表加入该策略（并开 `ENABLE_FILTERS`）。

## 说明

- 同花顺官方「hithink-finance」数据服务需要 API Key（https://fuyao.aicubes.cn/ 注册）。
- 低位判断、量价背离等策略均使用周K线数据，数据源会自动重采样。
- 历史日线数据已做本地缓存（cache/daily），之后只增量更新，减少请求量。
- 若需真实交易下单，可扩展 easytrader 等库。
